# AGENTS Guide (frontend)

Этот файл задает единый workflow для AI-агентов в этом репозитории.

## 1) Архитектурные границы

- Следуй FSD-структуре из `src/README.md`.
- Для route-файлов в `src/routes/**` соблюдай правило: в файле только `Route` через `createFileRoute`.
- Не редактируй вручную файлы в `src/codegen/**`.

## 2) Где размещать изменения

- Бизнес-оркестрация: `src/actions/<domain>`.
- Составные доменные UI-блоки: `src/widgets/<domain>`.
- Более простые UI-компоненты: `src/features/<domain>`.
- Общие компоненты/утилиты: `src/shared/**`.
- Техническая инфраструктура: `src/lib/**`.
- Страничная композиция: `src/entrypoints/**`.

## 3) Обязательный workflow перед завершением

1. Применить корректный слой/директорию для каждого изменения.
2. Если затронут роутинг, сгенерировать дерево роутов: `pnpm router:generate`.
3. Прогнать качество: `pnpm lint:fix` и `pnpm lint:typescript`.
4. Кратко отчитаться: что изменено, где, и как проверено.

## 4) Codegen workflow

- Обновление API-схем: `pnpm api:download`.
- Генерация API: `pnpm api:generate` (или `pnpm api:generate:hey-api` при явной необходимости).
- После генерации адаптируй только hand-written код вне `src/codegen/**`.

## 5) Импорты и стиль

- Используй алиас `@/*` для модулей из `src`.
- Соблюдай стиль из ESLint/Prettier (double quotes, sorted imports, semicolons).
- Предпочитай небольшие, целевые изменения без лишних рефакторингов.
