# Genario Frontend

React + TypeScript frontend for Genario, an AI-assisted scenario generation
product. The app is a Vite SPA with TanStack Router, TanStack Query, TanStack
Form, Tailwind CSS, limited i18next usage, and Kubb-generated API clients.

## Quick Start

```bash
pnpm install
pnpm dev
```

Production build:

```bash
pnpm build
```

Preview a built app:

```bash
pnpm start
```

## Main Scripts

```bash
pnpm dev                  # Vite dev server
pnpm build                # tsc --noEmit + Vite production build
pnpm start                # Vite preview on port 5173
pnpm lint:fix             # ESLint --fix + Prettier write
pnpm lint:typescript      # TypeScript check only
pnpm router:generate      # Generate TanStack route tree
pnpm router:watch         # Watch route tree generation
pnpm api:download         # Download OpenAPI schema to deps/api/product.json
pnpm api:generate         # Generate Kubb API code
pnpm api:generate:hey-api # Alternative generator, only when explicitly needed
pnpm i18n:resources       # Regenerate i18next resource types after intentional locale changes
```

There is currently no `pnpm test` script. Vitest is installed, but a project-wide
test workflow has not been standardized.

## Environment

Copy `.env.example` to `.env` for local development and fill the required Vite
environment variables. Keep real secrets out of the repository.

## Architecture

The app uses a pragmatic Feature-Sliced Design structure:

```text
src/
  routes/       TanStack Router file routes
  entrypoints/  Page-level composition
  widgets/      Complex domain blocks
  features/     Reusable domain UI and small domain helpers
  actions/      Business hooks wrapping API/query/mutation behavior
  shared/       Cross-domain UI, hooks, utils, constants, types
  lib/          Technical infrastructure
  codegen/      Generated API/router code
  globals/      Global TypeScript declarations
```

See `src/README.md` and `src/routes/README.md` for the detailed placement rules.

## Generated Code

- `src/codegen/api/product/**` is generated from `deps/api/product.json` by Kubb.
- `src/codegen/router/route-tree.gen.ts` is generated by TanStack Router.
- `src/globals/i18next-resources.d.ts` is generated from locale JSON files.
  Locale resources are currently used selectively, mainly for existing
  i18n-backed areas and pluralization/inflection, not as a default translation
  layer for every UI string.

Do not manually edit generated files. Update schemas/config/source files and run
the relevant generator.

## Agent Context

Coding agents should start with `AGENTS.md`. Tool-specific files such as
`CLAUDE.md`, `.cursor/rules/**`, and `.agents/skills/**` are scoped mirrors or
workflow helpers, not separate sources of truth.
