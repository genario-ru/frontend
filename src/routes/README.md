### Добавление новых route'ов

Каждый из файлов в папке route может содержать только константу Route, объявленную с помощью функции createFileRoute. Если нужно создать какие-то дополнительные функции / компоненты, то делаем мы это в соответствующих доменах в папках actions, entrypoints, features, widgets, shared и т.д. или inline'ом, если логика / компонет не крупные.
